# ForeverLink.love - 爱的永恒链接 💕

一个使用最激进前端动画库创建的浪漫主题网页，体现"爱的永恒链接"的美好寓意。

## ✨ 特色功能

### 🎨 使用的激进动画库
- **GSAP** - 业界最强大的JavaScript动画引擎
- **Three.js** - 3D WebGL图形库，创建3D爱心效果
- **Particles.js** - 粒子效果库，营造浪漫氛围
- **Anime.js** - 轻量级动画库
- **自定义高级效果系统** - 包括音效、光标效果、高级粒子系统等

### 💫 视觉效果
1. **3D旋转爱心** - 使用Three.js创建的3D心形动画
2. **粒子背景** - 动态连接的粒子网络
3. **无限符号动画** - 象征永恒的爱
4. **动态链条** - 连接两颗心的金色链条
5. **爱心雨效果** - 点击按钮触发的浪漫爱心雨
6. **光晕效果** - 旋转的光线营造梦幻氛围
7. **自定义光标** - 带有轨迹的特效光标
8. **渐变背景** - 动态变化的渐变色背景

### 🎵 交互功能
- **创建永恒链接** - 输入两个名字生成专属链接
- **音效系统** - 包括心跳声、魔法音效、叮当声
- **鼠标跟随** - 3D元素跟随鼠标移动
- **文字故障效果** - 悬停标题时的特效
- **粒子爆炸** - 生成链接时的庆祝效果
- **键盘快捷键** - 按空格键触发特效

## 🚀 快速开始

### 方法一：使用Python服务器（推荐）
```bash
# 确保已安装Python 3
python3 -m http.server 8080
```

### 方法二：使用Node.js的live-server
```bash
# 安装live-server（如果未安装）
npm install -g live-server

# 启动服务器
live-server --port=8080
```

### 方法三：直接打开
直接双击 `index.html` 文件在浏览器中打开（部分功能可能受限）

## 🎯 使用指南

1. **打开页面** - 访问 `http://localhost:8080`
2. **欣赏动画** - 页面加载时自动播放各种动画效果
3. **点击"创建永恒链接"** - 弹出输入框
4. **输入名字** - 输入两个名字，如"小明"和"小红"
5. **生成链接** - 点击生成按钮，创建专属的永恒链接
6. **享受特效** - 观看庆祝动画和粒子效果

## 🛠️ 技术栈

- **HTML5** - 语义化标记
- **CSS3** - 动画、渐变、3D变换
- **JavaScript ES6+** - 现代JavaScript语法
- **WebGL** - 3D图形渲染
- **Web Audio API** - 音效系统
- **Canvas API** - 粒子系统

## 🎨 自定义修改

### 修改颜色主题
在 `styles.css` 中修改颜色变量：
```css
/* 主要颜色 */
#ff6b9d  /* 粉红色 */
#feca57  /* 金色 */
#48dbfb  /* 天蓝色 */
#ff9ff3  /* 淡粉色 */
```

### 调整动画速度
在 `script.js` 中修改动画持续时间：
```javascript
duration: 2000  // 毫秒
```

### 添加新的爱心样式
在 `createHeartRain()` 函数中添加新的emoji：
```javascript
['❤️', '💕', '💖', '💝', '💗', '新的爱心']
```

## 🌟 特别功能

- **空格键快捷键** - 按空格键直接触发创建链接
- **ESC关闭模态框** - 按ESC键关闭输入框
- **点击外部关闭** - 点击模态框外部区域关闭

## 🔊 音效说明

页面包含3种音效：
1. **心跳声** - 低频脉冲音效
2. **魔法音** - 上升音调的神奇音效
3. **叮当声** - 三音阶和弦音效

首次点击页面任意位置激活音效系统。
