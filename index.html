a n i m e . j s

JavaScript animation engine

Simple

Anime.js works with CSS properties, SVG, DOM attributes and JavaScript Objects.

Powerful

Built-in staggering system, timeline, playback controls, and callbacks.

Flexible

Animate anything with a numerical value, in any unit.

anime({
  targets: '.basic-square',
  translateX: 250,
  rotate: '1turn',
  backgroundColor: '#FFF',
  duration: 800
});
